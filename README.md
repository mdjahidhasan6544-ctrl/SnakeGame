# Terminal Snake for Windows

A simple Snake game that runs directly in the terminal using only Python's standard library.

## Requirements

- Windows Terminal, Command Prompt, or PowerShell
- Python 3.10+

## How to play

1. Open this folder in a terminal window.
2. Run:
   ```bat
   python snake_game.py
   ```
   or double-click `run_snake.bat`.

## Controls

- `W`, `A`, `S`, `D` or arrow keys: move the snake
- `R`: restart after losing or winning
- `Q`: quit

## Gameplay

- Eat `*` food to grow and increase your score.
- Avoid walls and your own tail.
- Fill the whole board to win.
